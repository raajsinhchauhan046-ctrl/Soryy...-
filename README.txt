# Paayu...😘 — Sorry Website

A responsive, animated, multi-section apology website made with plain HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, or upload the folder to GitHub.
3. For a public link: create a GitHub repository, upload all three files (`index.html`, `style.css`, `script.js`), then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Wait for GitHub Pages to publish the website.

## Hindi sorry song
The site has a built-in **Add song** button. Tap it and choose an MP3/audio file saved on your device. The selected audio plays in the background while the page is open. No copyrighted song is bundled in this project; use an audio file you have permission to use.

## Customize
- Change Gujarati apology text in `index.html`.
- Change colours and animations in `style.css`.
- Change the number of floating SORRY words, button behavior, or love messages in `script.js`.

The page is built as three navigable sections (Home, Sorry note, Little love) so it works like a small multi-page experience without needing a server.
